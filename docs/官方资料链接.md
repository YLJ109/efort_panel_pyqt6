## 三、工程结构要点（摘自官方《软件使用说明》）

- RPL 工程 = **程序文件（Program，`.pgm`）** + **变量文件（Var，`.var`）**
- 默认工程：`main.pgm` + `main.var` / `module.var` / `external.var`
- **每个程序文件必须有一个同名的变量声明文件**（如 `main.pgm` ↔ `main.var`）
- **程序文件名必须以字母开头**，仅字母/数字/下划线，≤ 31 字符
- 变量用途：Module / Input / Output / Routine；
  存储方式：Var / CONST / RETAIN / PERSISTENT；
  作用域：LOCAL / GLOBAL / PUBLIC / TASK（后两者仅平台内部）
- 需要掉电保持的变量用系统自带的 `grpl` 变量
- **USE 盘导入程序时，扩展名必须大写 `.XPL`**（小写识别不到）
- 示教器【新建】有三选项 = **程序 / 工程 / XPL 程序**；【工程】生成 `.PJ` 容器，**程序管理器只识别 `.XPL`**

## 四、软 PLC 多任务（官方《ROBOX 多任务处理》）

- 可建 `PLC1.XPL` 作**后台任务**（**不能含运动指令**），切换到 `softplc1` 运行环境
- 【程序预约 APP】可设后台任务启动方式 = **指令启动 / 开机自启动**；前台可用 `CALL` 启停
- 变量族：掉电保持 `grpl.pBool/pInt/pReal[]`，常规 `grpl.gBool/gInt/gReal[]`
