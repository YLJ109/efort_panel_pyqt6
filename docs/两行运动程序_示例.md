# 两行运动程序 · 示例代码（某点 → 某点）

> 场景：程序只有两行运动指令，从当前位置走到第 1 点、再走到第 2 点。
> 语法依据：埃夫特官方《C30 RPL 指令手册》+《新版程序编辑器 操作手册》。

---

## ⭐ 最简做法（推荐）：两行 + 记录两个点，不用声明变量

**代码就两行：**

```rpl
MJOINT(POINTC(0,0,0,0,0,0,"CFG2",0,0,-1), v500, fine, tool0);
MJOINT(POINTC(0,0,0,0,0,0,"CFG2",0,0,-1), v500, fine, tool0);
```

> 括号里的数**不用你填** —— 在示教器上点【示教】按钮，它会自动把**当前位姿**写进去。
> 所以实际流程是"摇到位 → 点一下记录 → 再摇到下个位置 → 再点一下记录"。

**示教器操作（4 步）：**

| 步骤 | 操作 |
|---|---|
| 1 | 任务栏【**程序**】→ 进入程序界面（登录 `999999`） |
| 2 | **手动把机器人摇到第 1 个位置** → 左侧【指令栏】→【运动/Movement】→ 点 **MJOINT**<br>→ 点程序树里那行 → 右侧【参数】页 → **目标点**类型选「**固定 POINTC**」→ 点【**示教**】按钮（把当前位置记进去） |
| 3 | **摇到第 2 个位置** → 再点一次 **MJOINT** 加第二行 → 同样选「固定 POINTC」→ 点【**示教**】 |
| 4 | 点任务栏【**保存**】 |

**跑之前**：示教器模式切【**自动**】，速度先给 5%。

> 这就是全部 —— **固定 POINTC 是内联数值，不需要建变量、不需要配对 `.var`、不用敲一个字。**

---

## 一、最常用：关节运动 MJOINT（两行）

```rpl
MJOINT(P1, v500, fine, tool0);
MJOINT(P2, v500, fine, tool0);
```

- **MJOINT(目标点, 速度, 区域, 工具[, 参考坐标系]);**
- 默认值：速度 `v500`、区域 `fine`、工具 `tool0`、参考系 `wobj0`（可省略后两项）
- `fine` = 精确停点；要圆滑过渡可换 `z30` / `z50`

**速度写法两种**（按机器/版本选一种，别混）：
- **百分比**：`v100perc`（再乘全局倍率 40103 → 实际速度。上位机「速度 %」就是它）
- **绝对速度**：`v500` = 500 mm/s 量级

---

## 二、要走直线：MLIN（两行）

```rpl
MLIN(P1, v300, fine, tool0);
MLIN(P2, v300, fine, tool0);
```

> `MJOINT` 是**关节插补**（各轴同时到位，路径不可控）；
> `MLIN` 是**直线插补**（TCP 走直线）。**取放料、靠近工件时用 MLIN 更安全。**

---

## 三、"点"怎么写 —— 三种写法

| 写法 | 例子 | 说明 |
|---|---|---|
| **① 示教点（推荐）** | `MJOINT(P1, v500, fine, tool0);` | `P1` 是**变量点**：在示教器上把机器人摇到位置，点【记录】把当前位姿存进同名变量（存在配对的 `.var` 文件里）。**最省事、最不易错。** |
| **② 固定 POINTJ** | `MJOINT(POINTJ(0,-90,0,0,-90,0), v500, fine, tool0);` | 直接写 6 个**关节角**（度） |
| **③ 固定 POINTC** | `MJOINT(POINTC(337.34,399.67,155.27,95.19,-88.17,84.13,"CFG2",0,0,-1), v500, fine, tool0);` | 直接写笛卡尔位姿 x,y,z,a,b,c + CFG |

> 旧版示教器里 `MJOINT (*, v100perc, fine, tool0);` 中的 **`*` = 该程序配对 var 文件里记录的示教点**。

## 四、在示教器上怎么落进去（官方 5 步，全点选）

1. 任务栏【**程序**】→ 进入程序界面（登录密码 `999999`；需编程权限）
2. 左侧【**指令栏**】展开【**运动 / Movement**】→ 点 **MJOINT** → 指令进入右侧【程序树】
3. 点程序树里刚加的那行 → 右侧跳【**参数**】页
4. 设参数：
   - **速度 / 圆滑过渡 / 工具坐标系 / 用户坐标系** = **下拉选**
   - **目标点**：类型选「**变量点**」→点【选择变量】选 `P1`；
     或选「**固定 POINTJ / 固定 POINTC**」→ 点【**示教**】按钮把当前位姿记进去，或手输数值
5. 重复 2~4 再加第 2 条（目标点换成 `P2`），最后点任务栏【**保存**】

⚠ 官方原文：**"如不保存到文件，对程序的修改将是暂时的"**

## 五、完整最小程序（含变量声明，供对照）

```rpl
(* ============ 程序：TEST_MOVE ============ *)
(* 变量声明（写在配对的 .var 文件里）：
     Module  Var  POINTC  P1
     Module  Var  POINTC  P2
*)

MJOINT(P1, v500, fine, tool0);
MJOINT(P2, v500, fine, tool0);
```

**变量声明规则（官方）**：用途 `Module`/`Input`/`Output`/`Routine`，存储 `Var`/`CONST`/`RETAIN`/`PERSISTENT`；
**每个程序文件必须配一个同名变量文件**（如 `main.pgm` ↔ `main.var`）；文件名须**以字母开头**、≤31 字符。

## 六、跑起来之前的三个检查

1. **示教器切【自动】** —— 手动 T1/T2 下外部控制信号被禁用
2. **先用【测试跑】+ 2 秒定时试**：强制 5% 低速、到点自动停、越界还会熔断掐停；
   确认没问题再点【执行】跑完整的
3. **熔断兜底只作用于测试跑**：上位机每 200ms 采样，测试跑档位移超上限立刻 `0x1005` 停。
   【执行】档**不做越界检测**（作业程序本就要大幅运动），但报警/急停/通信/程序结束四道保护全在

> ⚠ **不要用 U 盘导入自己手写的 `.XPL`**：实测过 —— XPL 的代码是**结构化指令 XML**，
> 手写的文本文件导进去程序体不会被执行（表现为"程序在，就是不动"）。
> 要么在示教器上用【指令】栏点出来，要么用官方 PC 端软件下装。
