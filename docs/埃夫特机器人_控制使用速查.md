## 2. Modbus 寄存器（4xxxx 保持寄存器）

**只读 / 状态**

| 地址 | 含义 |
|---|---|
| `40001` | 状态位：Bit0 手动 / Bit1 自动 / Bit2 远程 / Bit3 伺服 / Bit4 报警 / Bit5 急停 / Bit6 程序运行 / Bit11 程序加载 / Bit12 伺服准备 |
| `40003` | 运行速度（%） |
| `40004` / `40005` | 报警码 1 / 2 |
| `40006` | 当前程序号 |
| **`40011~40022`** | **J1~J6 关节角（FLOAT，CDAB）** |

**可写 / 指令**

| 地址 | 含义 |
|---|---|
| `40101` | 指令位：Bit0 上下伺服 / Bit1 运行 / Bit2 停止 / **Bit3 清报警** / Bit4 加载 / Bit12 伺服使能 / Bit13 取消使能 |
| `40103` | 速度设定 |
| `40104` | 目标程序号 |

**命令字（必须"同沿"一条写入，且始终保留 Bit0 + Bit12）**

| 动作 | 值 |
|---|---|
| 伺服上电 | `0x1001` |
| 加载程序 | `0x1011` |
| 运行程序 | `0x1013` |
| 停止 | `0x1005` |
| 清报警 | `0x1009` |
| 取消使能 | `0x2000` |
| 全清 | `0x0000` |

⚠ **重新吸合序列**：`0x0000` → **等 0.6 秒** → `0x1001`（伺服吸合延迟实测 ≈0.55 s；只等 0.3 s 吸不上）。
写 `0x0000` 常常**不回正常应答但已生效** → 代码要容忍异常。

## 3. 硬规则（踩过的坑）

1. **先加载成功，才允许触发运行**。对着不存在的程序号发运行 = 控制器立刻报警 **5005**。
2. **必须是【自动】模式**。T1/T2 手动模式下**外部（Modbus）指令一律被忽略**，表现是"程序在、就是不动"。
3. **远程位（Bit2）不是门槛** —— 已证伪，不必去切。
4. **"假 5005"**：示教器处于**文件管理器/编辑程序**界面时，远程加载会被临时拒绝，照样回
   `5005 / 代码 -3` 但程序其实存在 ⇒ **遇到 5005 先让示教器退出文件界面再复测**，别急着下结论。
5. **加载前不要发停止（0x1005）** —— 实测停止之后控制器会拒绝加载。加载前只需清报警 + 撤触发。
6. **残留报警会堵住加载** —— 5005 挂着时加载必失败，加载前先 `0x1009` 清报警。
7. 加载失败会**抖动**（同一批程序同一秒内可能假失败），**多轮重试**是必须的。
8. **Modbus 没有关节级/点动指令** —— 让关节动的唯一路径是"控制器上有程序 → 加载 → 运行"。

## 4. 报警码速查

| 码 | 含义 | 处理 |
|---|---|---|
| **5005** | 远程加载程序错误，代码 −3 = **当前加载的程序不存在** | 确认程序号；排掉"假 5005" |
| **4902** | **XPL 文件 API 错误** ⇒ 文件在，但内容坏了/格式不对 | 重做程序文件 |
| **1812** | **安全门报警**（不是驱动器报警） | 检查安全门是否关好；`0x1009` 清 |
| 段位 | 1~999 系统 / 1800~1999 用户 Major / 3900~3999 Minor / 4900~4999 Warning | |

`0x1009` 清报警约 **0.12 s** 生效。

## 5. 现场 IO（以实机程序为证）

| 点位 | 含义 |
|---|---|
| **`io.DOut[8]`** | **吸真空**（置 `true` 就是吸） |
| **`io.DOut[9]`** | **破真空** |
| **`io.DIn[8]`** | 真空到位输入 |

⚠ **真空停不掉的经典原因**：程序里置过 `io.DOut[8] := true`，中途停止时**输出保持 1、不会自动复位**。
解法：跑一个只含 `io.DOut[8] := false` 的程序即可松开。

## 6. 外部寄存器 ↔ RPL 变量映射

命名规则 **`fidbus.mtcp_<sys|用户>_<ro|wo>_<b|i|r>[n]`**

| 地址 | 变量 | 方向 |
|---|---|---|
| `40001~40034` | `fidbus.mtcp_sys_wo_b/wo_i/wo_r[]` | 控制器 → PC（状态位 / 速度·报警码·程序号 / 关节角+笛卡尔） |
| **`40035~40092`** | **`fidbus.mtcp_wo_b/wo_i/wo_r[]`** | 控制器 → PC（用户发送端，可作"到位回执"） |
| `40101~40134` | `fidbus.mtcp_sys_ro_b/ro_i/ro_r[]` | PC → 控制器（命令位 / 速度设定·目标程序号） |
| **`40135~40138`** | **`fidbus.mtcp_ro_b[0..63]`** | PC → 控制器（布尔，可作"触发位"） |
| **`40139~40144`** | **`fidbus.mtcp_ro_i[0..5]`** | PC → 控制器（整数） |
| `40145~40192` | `fidbus.mtcp_ro_r[0..23]` | PC → 控制器（浮点） |
| `40301~40400` | `fidbus.mtcp_rw_b/i/r[]` | 用户可读可写 |

## 7. 在示教器上建/改程序的官方流程（通用 5 步）

1. 点任务栏【**程序**】进入程序界面（需编程权限）
2. 在**左侧指令栏**展开一级菜单（如"基本/Basic"），**点击**要用的指令 → 它被加进**程序树**
3. 点程序树里刚加的那行 → 右侧跳到【**参数**】标签页
4. 设参数：**变量类**参数点【**选择变量**】从候选列表选；
   **表达式类**参数点【**编辑**】→ 在表达式编辑器里写 → 确认 → 再点【**应用**】
5. 点任务栏【**保存**】
   ⚠ 官方原文："**如不保存到文件，对程序的修改将是暂时的**"

**常用指令形式**
- 赋值：`变量 := 表达式;`（参数不可手输，只能"选择变量"+ "编辑表达式"）
- 事件等待：`WAIT(condition,[timeout],[var]);`
- 关节运动：`MJOINT(目标点,速度,区域,工具,[参考坐标系]);` 默认 `v500 / fine / tool0 / wobj0`；
  目标点 5 类：**变量点 / 固定POINTJ / 固定POINTC / 固定EPOINTJ / 固定EPOINTC**
- 循环：`WHILE 条件 … ENDWHILE`（**键入 WHILE 时 ENDWHILE 自动添加**）；`FOR 变量 … END FOR;`
- 判断：`IF 条件 … ENDIF`（可加 ELSE）
- 注释：`(* … *)`
